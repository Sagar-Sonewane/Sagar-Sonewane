## 👋 About me

I'm an independent developer who builds self-directed projects end to end: product thinking, architecture, UI/UX, and shipping. I work with AI coding agents as a core part of my workflow, and I treat their output as *unverified until I've tested it myself*.

- 🔭 Currently building **StudySync**, a realtime voice + whiteboard collaboration app
- 🎨 Care a lot about design: marker/paper aesthetics, skeuomorphic UIs, details that feel alive
- 🧠 Into architecture, product design, and prompt engineering
- 🏆 Led teams in multiple hackathons

## 🚀 Featured Projects

### 🧑‍🏫 StudySync
> Realtime collaboration: voice chat plus an infinite shared whiteboard.

- Host-controlled drawing permissions, grace-period flows, and reconnect handling
- Freemium model with Stripe billing tied to the host
- **Stack:** React · Vite · Tailwind · Node · Express · WebSocket · tldraw · Yjs · LiveKit · Supabase · Prisma · Stripe

### 📻 Masterji Ka Radio
> A skeuomorphic vintage-radio music site. *"hamare zamane ki vibe."*

- Playback via the YouTube IFrame API, with server-side Data API v3 fetching and caching to respect free quotas
- Animated drawer, live progress bar, real playlist data
- **Stack:** Next.js 14 · TypeScript · Tailwind · Framer Motion · Vercel

## ⚡ How I Build

- **Docs-first with agents:** context files in `/docs` keep AI coding agents aligned across sessions
- **Trust, but verify:** agent-reported status is a claim, not a fact, until I've tested it
- **Design with intent:** consistent systems (type, palette, shadows) over one-off styling
- **Ship, then iterate:** small phases, real testing, quick fixes
